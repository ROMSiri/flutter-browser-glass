# Матовый дизайн браузера (Android)

## Что изменилось

**Нижняя стеклянная панель** (`lib/glass/glass_bottom_bar.dart`) вместо верхней:
- слева кнопка меню, по центру адресная строка, справа кнопка вкладок с числом вкладок;
- все три части — отдельные формы из матового стекла (размытие + заливка) одной высоты;
- листаешь страницу вниз — строка сжимается до домена, кнопки размываются и уходят под неё; вверх — возвращаются;
- каждая часть тянется отдельно: зажал — чуть увеличилась, тянешь — туго, отпустил — пружинкой на место; под пальцем синеет;
- тап по строке — ввод адреса или поискового запроса, замок — сведения о сайте, стрелка справа — обновить;
- синяя полоска загрузки внутри строки;
- долгое нажатие на кнопку вкладок — быстрое меню (новая вкладка, инкогнито, закрыть все).

**Пружинное меню** (`lib/glass/glass_menu.dart`): вырастает из кнопки и уходит обратно, пункт под пальцем загорается синим, отпустил — выбран; панель можно потянуть. Сверху ряд: назад, вперёд, обновить, в избранное, поделиться.

**Экран вкладок** (`lib/glass/glass_tabs_page.dart`): карточки со снимками в две колонки, смахивание — закрыть, снизу «+», «Готово» и меню.

**Также переоформлены:** пустая вкладка (строка поиска и избранное плитками), поиск по странице (стеклянная строка снизу), избранное / история / сохранённые страницы / скриншот — стеклянные панели снизу, окно сведений о сайте выезжает снизу, верхние панели настроек и консоли — матовые.

**Тема:** светлая / тёмная / как в системе — в меню («Тёмная тема») и в Настройках («Тема»). Выбор запоминается.

Логика браузера (вкладки, история, загрузки, настройки WebView) не менялась. Версия для компьютера (Windows/macOS) осталась со старой панелью.

## Файлы
- новые: `lib/glass/*.dart`
- изменены: `lib/main.dart`, `lib/browser.dart`, `lib/webview_tab.dart`, `lib/empty_tab.dart`, `lib/custom_popup_dialog.dart`, `lib/app_bar/url_info_popup.dart`, `lib/app_bar/custom_app_bar_wrapper.dart`, `lib/app_bar/certificates_info_popup.dart`, `lib/javascript_console_result.dart`, `lib/long_press_alert_dialog.dart`, `lib/models/browser_model.dart`, `lib/pages/settings/main.dart`, `lib/pages/settings/cross_platform_settings.dart`

## Сборка APK
```
flutter pub get
flutter build apk --release
```
Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.
Или откройте папку проекта в Android Studio и нажмите Run.

## Важно
- Чтобы стекло размывало страницу под собой, WebView на Android переведён в режим `useHybridComposition = false` (`lib/webview_tab.dart`). Если на каком-то устройстве будут проблемы с вводом текста на сайтах, верните `true` — панель останется, но размытие страницы под ней будет слабее.
- Проект писался без возможности собрать его в этой среде. Если при сборке появится ошибка — пришлите её текст, исправлю.
